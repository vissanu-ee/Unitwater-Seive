ตัวแปรที่ใช้

a = Wt. of container (ลิงก์จากชีต 1)

b = Wet soil + container (ลิงก์จากชีต 1)

c = Dry soil + container (ลิงก์จากชีต 1)

d = c − a : Mass of dry sample, gm.

e = (b − c) / d × 100 : Mass of dish gm. (w%)

f = ค่า Retained (gm)

g = f − a : cum. wt. retained

h = g / (d / 100) : % retained

i = 100 − h : % Finer
